# Piezas de ajedrez (SVG)

Set original de piezas 2D estilo Staunton, dibujado para esta plataforma educativa.

- No deriva de Lichess, Chess.com ni de sus assets propietarios.
- Formato: SVG vectorial, una pieza por archivo (`wK.svg` = rey blanco, `bN.svg` = caballo negro).
- Licencia: la misma que el resto del proyecto (uso educativo de Ajedrez Escolar).
